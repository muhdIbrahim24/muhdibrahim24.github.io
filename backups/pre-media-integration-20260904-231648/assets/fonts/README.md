# Local web fonts

- `montserrat-variable-latin.woff2`: Montserrat variable font for display headings.
- `inter-variable-latin.woff2`: Inter variable font for body and utility text.
- `Montserrat-OFL.txt` and `Inter-OFL.txt`: SIL Open Font License texts supplied with the respective Google Fonts families.

Both fonts are self-hosted, preloaded from `index.html`, and used without a remote runtime request. Montserrat is NYU’s listed fallback; Inter is used by NYU Tandon. Perstare is not bundled because its distribution is restricted.
