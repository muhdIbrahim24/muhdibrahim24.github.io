# Project cover-image prompts (Google Gemini / "Nano Banana")

Thirteen prompts, one per project, written for Gemini's image model (Nano Banana). Paste one prompt at a time — generating them separately gives Gemini a cleaner shot at each subject than batching several into one request.

A shared house style is baked into every prompt below so the thirteen covers read as one consistent set rather than thirteen random images: editorial engineering-photography lighting, a restrained neutral-to-warm-grey palette with room for one muted accent colour, shallow depth of field, no visible text, logos, watermarks, UI overlays or sponsor branding, and a wide 3:2 crop that works as a horizontal cover card. If Gemini's first pass looks too busy or too "AI-generated," add: *"simplify the background, remove any invented text or labels, make the lighting softer and more photographic."*

Where a project has a real physical prototype, the prompt asks for product/documentary photography of that object. Where the project is purely computational (the PDE study, the PCA study, the quantum-feasibility report), the prompt asks for an abstract technical visualisation instead, since there is no physical artefact to photograph.

---

## 1. Advanced Anti-Roll Tank System (ART3S)

```
A photorealistic cutaway engineering render of a large cargo ship's hull, viewed from the side, revealing an anti-roll tank system built into the lower hull: two water reservoirs, one on each side of the ship, connected beneath the keel by a U-shaped tube, with visible water at rest inside them. Dramatic single-source side lighting picks out the curved steel hull plating and the water's surface. Muted blue-grey and steel-tone palette with one warm accent light. Clean marine-engineering visualisation style, similar to a shipyard technical illustration rendered with photographic lighting. No text, no labels, no logos, no crew or people. Wide 3:2 composition, the ship's midsection filling the frame.
```

## 2. Savonius Turbine for Traffic Wind Energy Harvesting

Long-exposure light trails from passing traffic streak past on both sides, motion-blurred and out of focus, while the turbine itself is sharp and the clear subject of the frame. Cool blue dusk sky above, warm amber light trails below. Documentary engineering-photography style, shallow depth of field isolating the turbine. No text, no logos, no visible license plates or faces. Wide 3:2 composition.

## 6. Indoor Wireless Link Design with Helmholtz PDEs

### Using these

Gemini/Nano Banana sometimes adds stray text or a logo-like mark even when told not to — regenerate that one image, or add *"absolutely no text or symbols anywhere in the image"* to the end of the prompt. If a result comes back too literal or too "renderish," add *"photographed with a real camera, natural lens imperfections, no CGI look."* Once you have images you like, drop the files in and I'll wire each one in as the project's cover plate and crop/resize it to match the site's card proportions.
